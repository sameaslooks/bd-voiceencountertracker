Window layouts
Setup — for 30 s the overlay takes the mouse even inside the game and turns translucent: switch to the game and drag it where you want; empty frames stand in for the stream (big and preview) and the notifications. It's saved 5 s after your last move. Save stores where the windows are right now. A saved layout comes back whenever that game is in front; Desktop is used everywhere else. Games show up here once you've played them with the overlay running.
